Collection Description
The Express API in server/index.js, http://localhost:8887 in development. Every endpoint that touches a child reads through the CALLER'S OWN Supabase token, so Row-Level Security answers 'may they see this' rather than JavaScript. Folders 1, 3 and 5 need no account; folder 4 needs authEmail and authPassword in the environment.
